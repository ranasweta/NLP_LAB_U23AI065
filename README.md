## Introduction

This repository supports a series of NLP lab assignments, covering foundational and advanced topics. Each lab includes sample code, datasets, and step-by-step instructions to guide you through practical NLP tasks.

## Features

- Modular lab structure for easy navigation
- Sample datasets for experimentation
- Well-documented code and instructions
- Ready-to-use Python scripts for each exercise
- Requirements file for quick setup

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd NLP_LAB_U23AI065
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Lab Exercises

- **LAB_1:**  
  Learn how to tokenize text, clean data, and perform basic preprocessing.

- **LAB_2:**  
  Explore text classification techniques and perform sentiment analysis using machine learning models.

- **LAB_3:**  
  Implement Named Entity Recognition (NER) and experiment with advanced NLP tasks.

Each lab folder contains Python scripts, sample data, and detailed instructions. Refer to the code comments and any additional README files within each lab for guidance.

## Requirements

- Python 3.8 or higher
- All required Python packages are listed in `requirements.txt`

## Usage

1. Navigate to the desired lab folder:
   ```bash
   cd LAB_1
   ```
2. Review the instructions in the lab's README or code comments.
3. Run the scripts:
   ```bash
   python <script_name>.py
   ```
