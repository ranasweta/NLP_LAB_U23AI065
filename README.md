## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd NLP_LAB_U23AI065
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Lab Exercises

- **LAB_1:** Tokenization and basic text processing.
- **LAB_2:** Text classification and sentiment analysis.
- **LAB_3:** Named Entity Recognition and advanced NLP tasks.

Each lab folder contains code, sample data, and instructions.

## Requirements

- Python 3.8+
- See `requirements.txt` for required Python packages.

## Usage

1. Navigate to the desired lab folder.
2. Follow the instructions in the respective lab's README or code comments.
3. Run scripts using:
   ```bash
   python <script_name>.py
   ```
